# PPTSave

PPTSave 是一款 Windows 后台工具，可自动识别在 WPS、PowerPoint 或 PDF 阅读器中已打开的本地、U 盘 PPT / PDF 文件，将已保存到磁盘的内容复制到指定目录。保留原文件名，相同内容不重复保存；文件修改并保存后，可留存新的版本。识别能力受阅读器及打开方式影响，具体边界见下文。

## 安装和使用

1. 前往 [Releases 下载页](https://github.com/duzhongrongdzr-del/PPT-PDF-Automatic-Save-As-Tool/releases)，在最新版本的 **Assets** 中下载 **PPTSave-Windows-x64.zip**。`Source code` 是源码，不含 EXE。
2. 将压缩包完整解压到固定位置，进入 **PPTSave** 文件夹，双击 **PPTSave.exe**。请保留旁边的 `_internal` 文件夹。
3. 首次运行时选择一个专门的副本保存目录，例如 `D:\报告留存`。
4. 正常打开本地或 U 盘中的 PPT / PDF，保持打开约 15 秒，点击“打开目录”检查副本。
5. 关闭窗口后，程序仍在系统托盘运行。可暂停 / 继续监测；完全停止请右键绿色托盘图标 →“退出”。需要开机运行时，勾选“登录 Windows 后自动运行”。

适用于 **Windows 10 / 11 x64**，无需安装 Python。程序应运行在打开文稿的同一台电脑上。

**更新：**先从托盘退出旧版，再解压并运行新版。新版自动接续旧版保存目录和去重记录；已启用的开机启动会更新到当前程序位置。已有副本保留原位置。配置和日志位于 `%LOCALAPPDATA%\PPTSave`。

**卸载：**取消开机启动并退出，再删除程序文件夹；已保存的文稿副本不会被删除。

## 功能、保存规则与识别范围

- **支持格式：**`.ppt`、`.pptx`、`.pptm`、`.pps`、`.ppsx`、`.ppsm`、`.pdf`，共用一个保存目录。
- **保留原名：**按“年-月”分文件夹保存，文件名和扩展名不变。同名但内容不同的文件放入“其他版本”子目录，不覆盖旧文件。
- **内容去重：**同一内容即使改名或换了来源，也只留存一份，保留首次确认的原名；修改并保存后产生新版本。删除副本后，再次识别到源文件可补存。
- **目录管理：**切换目录后在新目录建立记录，不搬运原有副本。`.pptsave` 文件夹保存去重记录，请勿手动修改。
- **识别范围：**PPT 面向 WPS 演示、PowerPoint；PDF 尝试识别 WPS PDF、Adobe Reader / Acrobat、福昕、PDF-XChange、SumatraPDF，以及 Edge / Chrome / Firefox 打开的本地 PDF。不同版本兼容性可能不同。
- **本机处理：**不修改源文件，不执行文稿宏，不上传文稿内容。支持后台监测、暂停 / 继续、开机启动及导出诊断。

## 识别边界

- 只能复制已保存到磁盘且可读取的文件，不包含未保存的编辑；不自动下载云端文稿、网页或在线 PDF。
- 阅读器不暴露文件路径、浏览器新标签页、窗口标题被 PDF 内部标题替代等情况，可能无法识别；也可能识别到阅读器仍持有的最近文件或预览文件，不能保证与当前标签页一一对应。
- 仅识别到临时文件且无法确认原名时，副本放入“待确认原名”子目录，不猜测原名；之后若能核实对应源文件，会恢复原名。
- 很快打开又关闭、提前拔出 U 盘、权限不足、磁盘空间不足等情况可能漏存或延迟。建议保持文件打开至少 15 秒并检查结果；不支持多台电脑同时写入同一归档目录。

识别不到时，可点击“导出诊断”反馈问题。诊断包含本机路径和相关进程信息，不包含文稿内容，也不会自动发送；分享前请检查敏感信息。
