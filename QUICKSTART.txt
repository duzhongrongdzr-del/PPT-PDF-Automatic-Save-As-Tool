知庭 · PPT / PDF 自动留存 0.2.0（Windows x64 测试版）

本版新增 PDF，和 PPT 共用原有保存目录，默认启用。
保留源文件名。同名但内容不同的文件放入不同子文件夹，文件名不变。
升级前，请右键旧程序的托盘图标 → 退出，再运行新版本。
如果设置了开机启动并更换了程序位置，请取消后重新勾选开机启动。

1. 解压整个 ZIP 到固定位置，保留 _internal 文件夹。
2. 双击 ZhitingPPTSave.exe，首次选择保存目录。
3. 在 WPS 打开本地或 U 盘 PPT / PDF，保持打开 15 秒。
4. 点“打开目录”，确认副本存在且能打开。
5. 把原 PPT 改名再打开，确认不重复保存。
6. 修改原 PPT 并保存，确认新增版本。

如果出现“待确认原名”文件夹，说明只识别到临时文件，尚不能确认原名。
请从程序设置导出诊断，以便继续适配该 WPS 版本。

关闭设置窗口会收起到托盘，监测继续。
完全停止：右键右下角绿色图标 → 退出。
识别不到：打开设置 → 导出诊断，可反馈 WPS 版本及诊断文件。

PPT / PDF 不会上传 GitHub 或其他服务器。未保存的编辑无法复制。
WPS / PowerPoint 兼容性需要在本机实测，详见 README.md。

PDF 识别尝试支持 WPS PDF、Adobe、福昕等桌面阅读器，以及浏览器中的本地 PDF。
没有本地文件的在线 PDF 不会自动下载；具体阅读器兼容性需要在本机实测。
